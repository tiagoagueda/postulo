# The country flags Postulo serves, one ISO 3166-1 alpha-2 code per line, lower case.
# `npm run sync:flags` copies exactly these from the flag-icons package into
# src/postulo/static/flags/ and removes any file there that is not listed.
#
# This is every country the telephone field offers, because any of them can be chosen and
# the field shows the chosen one's flag. The language picker's flags are a subset: each
# language names the country it is most plainly at home in, and that country is in here
# already. `tests/test_flags.py` fails if this list and `core/phones.py` disagree, so a
# country added there is a flag missing here until the script is run and both committed.
#
# Artwork: https://github.com/lipis/flag-icons (MIT). The licence is copied in beside the
# files as LICENSE.txt.
