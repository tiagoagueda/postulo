{% load i18n %} {% comment %} Both links carry an id because htmx puts focus back after a swap only for an element that has one, and these two swap themselves away. Without them the Tab after paging started again at the skip link, so somebody working through a long list by keyboard began the page from the top every time (#227). They also name a focus group, because an id is only half an answer: the last page has no *Next* at all, so there is no element left for htmx to put focus back on.
