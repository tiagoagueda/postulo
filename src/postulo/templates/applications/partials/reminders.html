{% load i18n %} {% comment %} What is still outstanding, and what can be done about one (#257, #238). A reminder's *Done* removes the control that was pressed, which is the shape #227 is about: a control that swaps itself away has to hand focus somewhere, or the next Tab starts again at the skip link. `hx-focus-after` names where -- the next tick if there is one, the heading if that was the last -- and `app.js` does the handing over. *Later* swaps the same region, and the row **stays**: a reminder put off until next week is still outstanding and still this application's, so what changes is the date under it. Nothing is handed anywhere, because nothing was taken away. `aria-live="polite"` for the same reason as the timeline: the row disappearing is the only sign that anything happened, and a disappearance is not something a screen reader announces by itself. {% endcomment %}
