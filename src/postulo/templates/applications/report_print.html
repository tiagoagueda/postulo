{% load i18n %} {% comment %} The report as a document to hand over (#56). A separate template from the page, not a print stylesheet over it. The page is a place to choose a period and follow a link; the document is a fixed thing with a name, a period and the date it was produced on it, because a document with no date is not evidence of anything. Sharing one template would have meant hiding half of each from the other. **The stylesheet is inline here and only here.** Nothing serves this to a browser: it is rendered to a PDF by WeasyPrint in the same process, so it never meets the content security policy and must never fetch anything -- a renderer that reaches the network or the disk for a stylesheet is a renderer that produces a different document depending on where it runs. **Every side is logical.** A report written in Arabic or Hebrew lays out from the other edge, and WeasyPrint honours `dir` on the root element, so `margin-inline-start` is the only kind of margin here. {% endcomment %} {% blocktranslate with period=report.period.label %}Job search report · {{ period }}{% endblocktranslate %}
