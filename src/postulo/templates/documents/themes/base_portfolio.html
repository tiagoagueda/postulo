{% load i18n %} {% comment %} The structure every portfolio theme shares (#133). A separate base from `base_cv.html` rather than a flag inside it, because the two differ in the one thing a document's structure is *for*: the order of the argument. A CV is a career read backwards, and the dates carry it. A portfolio leads with the work — what it was, what it points at, what came of it — and the career follows as context. Everything below it is the same machinery: the same `CVItem` selection, the same sections, the same overrides. What changes is which section goes first and how an entry is set.
