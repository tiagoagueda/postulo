{% load i18n postulo %} {% comment %} A list with nothing in it (#292). `what to do` There were sixteen of these and they were written two ways: a card with a bold line, a quiet line and a button, or a card with one grey sentence. Neither was wrong and nothing made them agree, so an empty *Applications* and an empty *Tags* looked like pages from different applications. Basecoat's `empty` supplies the structure -- a centred column with a header, a body and a footer -- and the paint is this project's. The icon is optional and always decorative: it repeats what the sentence beside it already says, so a screen reader is not told twice. The action carries `action_variant` for the one distinction that matters: a page with nothing on it yet offers the thing to do next as a primary button, while a filter that matched nothing offers *Clear* as an outline, because clearing is a way back rather than a way on. Three shapes, one component (#291). The default is the page's own empty state: a card, centred, with room around it. `variant="quiet"` is the note a widget or an aside leaves where its list would be -- "Nothing due." -- a card with one muted sentence, left-aligned, because a dashboard tile is not a page and does not get a page's ceremony. `variant="row"` is the same sentence inside a box that already is a card, a list with no rows: no card of its own, the row's padding. Forty-seven of these were written by hand in five shapes; the test in `tests/test_design_gallery.py` holds that number at nought. {% endcomment %}
