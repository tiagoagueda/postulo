{% load i18n postulo %} {% comment %} One identifier: what kind, the value, and -- when the kind is Other -- a name for it. The same row on a company's form and on *Your details*, which used to be two byte-identical copies (#284). The name box is drawn only when it means something. The display side has always followed that rule (`scheme_label` uses the label only for Other); the form contradicted it with an empty box on every row, the widest thing competing with the value for space. The row knows its kind when it renders, and `:has()` in the stylesheet follows the select as it changes, so no script is needed for the box to appear when Other is chosen. A row that somehow carries a name with another kind -- every row written before this could -- keeps the box, because hiding a value makes it invisible and unremovable; the form blanks such a name on save, so the row cleans itself up the next time it is touched. {% endcomment %}
