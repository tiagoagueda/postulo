{% load i18n %} {% comment %} The identifier schemes an instance defines for itself: the box of JSON, and what a scheme can say (#311). ``, with the `IdentifierSchemesForm`. A component because it is drawn on two pages: inside the dialog on *Plugins*, and on the page of its own that the dialog falls back to with scripts off. It is also what the dialog is sent back when the text is refused, which is why the whole of it sits in one element with an id: that element is what the answer replaces, so the dialog stays open over what was typed, with the sentences that say what is wrong and the line each is on. **What is wrong is said above the box, not under it.** The row is written out for that and not drawn by ``, which puts a field's errors after its control. The box holds a hundred lines; under it, the sentence that refused them was the last thing on the page, and the only change anybody saw was a label gone red. Above it, the sentences are the first thing read after the label, and the box they are about is the next. They keep the id Django's `aria-describedby` names and the `role="alert"` a swap is announced by, so they are tied to the box as every field's errors are. The same region says what is wrong with the text **as it is kept**, when the page is asked for and nothing has been posted (`IdentifierSchemesForm.showing`): a sentence that says so comes first, because nothing was refused and the reader has typed nothing. The box is a box of code (`data-code`): a height of its own, scrolling inside itself. The list under it is the whole reference, folded away: what each name means, and one scheme written out. The names and the example are code, set left to right in any language. It keeps a measure of its own, 48rem, which is the wide dialog's: a box somebody types into never runs the width of whatever it was put in (#320). {% endcomment %}

{% translate "What a scheme can say" %}
key
{% translate "What a row stores: lower-case letters, digits and hyphens. Never a key of one of Postulo's own schemes, which are added to and never changed." %}
label
{% translate "Its name, in double quotes, or one name for each language, as in the example. A reader is shown the one closest to their language." %}
subjects
{% translate "What it identifies: “person”, “company” or both. It is offered on Your details, on a company's form, or on both." %}
pattern
{% blocktranslate trimmed %} What a value looks like, from its first character to its last. A character stands for itself. A class is one character out of several: [A-Z], [0-9a-f], [^ ] for anything but a space, \d for a digit, \w for a letter, a digit or an underscore. A count follows what it counts: {4}, {2,5}, or ? for one or none. Alternatives are separated by |, and a fixed separator sits in round brackets: ( - )?. {% endblocktranslate %} {% blocktranslate trimmed %} It is not a regular expression: nothing repeats without a limit, and where one part ends and the next begins must never be in doubt. In JSON a backslash is written twice, \\d. {% endblocktranslate %}
link
{% blocktranslate trimmed %}Where a value leads: an http or https address with {value} where the identifier goes, after the host. person_link is the address for a person, where that is another one.{% endblocktranslate %}
example
{% translate "A value the scheme accepts. It is shown where the kinds are listed, and in the sentence that refuses a value of another shape." %}
upper, lower
{% blocktranslate trimmed %}true to put what was typed into capitals, or into small letters, before it is checked.{% endblocktranslate %}
checksum
{% blocktranslate trimmed %}iso7064-mod11-2, which an ORCID ends in, or iso7064-mod97-10, which a legal-entity identifier ends in. No other can be named.{% endblocktranslate %}
