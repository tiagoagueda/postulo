{% blocktranslate trimmed %} A CV photo is a photograph for your CVs, kept apart from your picture above: the picture stands for you on these pages, and the CV photo is only ever printed on a CV. {% endblocktranslate %}

{% blocktranslate trimmed %} It is kept as you frame it. Postulo does not crop it, because the theme that prints it decides whether it is a portrait, a square or a circle. It is straightened and saved again, which drops what the file knew about where it was taken. {% endblocktranslate %}

{% blocktranslate trimmed %} A CV prints the photo only when you tick that on the CV. The plain text and the Word file never carry it. Tick Remove the CV photo and save to take it away. {% endblocktranslate %}
