{% load i18n %} {% comment %} The help of *Social profiles*, *Code repositories* and *Websites* (#302): one topic for the cards of links, which work the same way. Drawn by their drawer and by the page at /help/links/. {% endcomment %}

{% blocktranslate trimmed %} Social profiles, code repositories and websites work the same way, each on a card of its own: one row for each address, as many as are worth showing. A new one goes in the empty row at the end of the list, and saving the page adds it. {% endblocktranslate %}

{% blocktranslate trimmed %} Where a card has a Service menu, choose the service the address is on. Its icon is shown beside it, and the address is checked against what an address on that service looks like, so a mistyped one is refused, and the refusal says why. Paste an address without choosing a service, and saving chooses it where the address is on one Postulo knows. {% endblocktranslate %}

{% blocktranslate trimmed %} Other takes any web address, and a name to show for it; left blank, the name is the address's host. A card with no Service menu takes any address in the same way. Under a named service a row has no name of its own: the service is its name. {% endblocktranslate %}

{% blocktranslate trimmed %} Postulo never opens a link on its own: not to check that it answers, not for an icon, not for a picture. The address is kept as you typed it, with https:// put in front where you left it out. {% endblocktranslate %}

{% blocktranslate trimmed %} The filled star marks the primary of each sort: the one a CV prints, unless its own Settings say otherwise. Letters print none. Press another row's star and save to change it. The bin removes a row at once, after asking, without waiting for Save. {% endblocktranslate %}
