{% load i18n %} {% comment %} The help of *Telephone numbers* (#302), drawn by the card's drawer and by the page at /help/telephone-numbers/. {% endcomment %}

{% blocktranslate trimmed %} One row for each number. A new number goes in the empty row at the end of the list: saving the page adds it and offers another empty row. {% endblocktranslate %}

{% blocktranslate trimmed %} Kind says what the number is, and can be left blank. Choose Other and a box asks what to call it. {% endblocktranslate %}

{% blocktranslate trimmed %} Choose the country the number is in and type the number the way it is written there. Or type it in full, starting with +, and the country chosen is ignored. It is kept in the international form, so it can be dialled from anywhere, and documents print it grouped the way its country writes it. {% endblocktranslate %}

{% blocktranslate trimmed %} A number its country cannot have is refused, and the refusal says why. A number Postulo cannot place is kept as you typed it, with a note beside it. One recorded before numbers were checked stays as it is, marked, until you change it. Nothing here proves that a number is yours. {% endblocktranslate %}

{% blocktranslate trimmed %} A number in its international form is kept once on this instance. If it is already recorded here, saving says so, and takes it from nobody. {% endblocktranslate %}

{% blocktranslate trimmed %} The filled star marks the primary: the number your documents print, unless a CV's own Settings say otherwise. Press another row's star and save to change it. The bin removes a row at once, after asking, without waiting for Save; removing the primary gives the star to another number, as the question says before you answer it. {% endblocktranslate %}

{% blocktranslate trimmed %} Where this instance can send a code to a telephone, a number you have confirmed can also be the one that gets you back into your account. That choice is separate from the primary, so changing what a recruiter dials never changes how you prove it is you. The bin will not remove that number while it is your way in. Changing its digits makes it another number, which has to be confirmed again and is no longer your way in. {% endblocktranslate %}
