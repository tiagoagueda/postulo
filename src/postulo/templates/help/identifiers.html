{% load i18n %} {% comment %} The help of *Identifiers* (#302), drawn by the card's drawer and by the page at /help/identifiers/. `pasted` is the registers whose address can be pasted whole, from `accounts.identifiers.pasted_whole()`: the schemes that lift an identifier out of an address on their own host, never written out here. {% endcomment %}

{% blocktranslate trimmed %} A name is not an identity: two researchers share one, and one researcher publishes under three. An identifier says which person you are whatever the name, and an application form for an academic post asks for an ORCID by name. {% endblocktranslate %}

{% blocktranslate trimmed %} Kind is the register the identifier belongs to, and What goes where shows what each one looks like. Other takes anything else, with a name you give it. {% endblocktranslate %}

{% blocktranslate trimmed %} An address on {{ pasted }} can be pasted whole: Postulo keeps the identifier. Each register's identifiers are tidied into its own spelling and checked against the shape they have, and where a register builds a check into its identifiers, as an ORCID's last character is, a mistyped one is refused with the reason. Nothing is ever looked up: Postulo asks no register anything. {% endblocktranslate %}

{% blocktranslate trimmed %} You can have one of each kind, except Other. A kind you have already recorded cannot be chosen on another row, and saving refuses a second one and says which kind it is. Saving adds the row you filled in and offers an empty one for the next. {% endblocktranslate %}

{% blocktranslate trimmed %} A CV prints your identifiers in its contact block: all of them, the ones you tick for it, or none, as its own Settings say. The bin removes a row at once, after asking, and its kind can then be chosen again. {% endblocktranslate %}
