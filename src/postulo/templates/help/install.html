{% load i18n %} {% comment %} How to install the site as an app (#895): where the account menu's *Install* leads on a browser that does not offer to install by itself, Safari above all, and the page at /help/install/. {% endcomment %}

{% blocktranslate trimmed %} Installed, it opens in a window of its own, from an icon on the home screen, in the Dock or in the list of apps, without the browser's address bar and tabs. It is still this site: you sign in the same way, and everything stays on the server. {% endblocktranslate %}

{% blocktranslate trimmed %} Safari on an iPhone or iPad: press the Share button, then Add to Home Screen. {% endblocktranslate %}

{% blocktranslate trimmed %} Safari on a Mac: choose Add to Dock from the File menu, or from the Share button. {% endblocktranslate %}

{% blocktranslate trimmed %} Chrome, Edge, Brave and other browsers built on Chromium: the account menu offers Install where the browser allows it. The browser's own menu has the same entry, and on a computer so does the icon at the end of the address bar. {% endblocktranslate %}

{% blocktranslate trimmed %} Firefox on Android: choose Add to Home screen from the browser's menu. Firefox on Windows can add a site to the taskbar once Add sites to your taskbar is switched on under Settings → Firefox Labs. Firefox on other computers does not install sites as apps; open this site in one of the browsers above. {% endblocktranslate %}

{% blocktranslate trimmed %} Without a connection, the installed app shows a page saying it cannot reach its server, instead of the browser's own error. That page is the only thing it keeps on the device: nothing of your applications, documents or contacts is stored there. {% endblocktranslate %}

{% blocktranslate trimmed %} A site can only be installed when it is served over HTTPS. If no browser offers to install it, ask whoever runs this server. {% endblocktranslate %}
