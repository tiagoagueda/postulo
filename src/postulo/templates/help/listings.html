{% blocktranslate trimmed %} A listing is a posting you have noticed, before you have decided anything about it. Capture a posting reads one from its address; Add a listing is for one you type in yourself, such as a role you heard about. {% endblocktranslate %}

{% blocktranslate trimmed %} Each listing is new until you decide. Shortlist keeps the ones worth a closer look, Discard puts away the ones that are not, with the reason if you want to give one, and Apply turns a listing into an application. A discarded listing can be restored. {% endblocktranslate %}

{% blocktranslate trimmed %} The tabs sort them by where they stand, and the search box over the table narrows what is listed. Columns and filters can be chosen and kept as a saved view. {% endblocktranslate %}

{% blocktranslate trimmed %} A listing's page names the skills of the ESCO classification its text asks for, and says which of them your career record has and which it does not. Nothing is guessed: a skill counts where the listing uses its name, and you have it where one of your skills is that same skill. {% endblocktranslate %}
