{% load i18n %} {% comment %} The help of *Postal addresses* (#302), drawn by the card's drawer and by the page at /help/postal-addresses/. {% endcomment %}

{% blocktranslate trimmed %} One row for each address you want to keep. Kind says which it is and can be left blank. Choose Other and a box asks what to call it. {% endblocktranslate %}

{% blocktranslate trimmed %} While Address rules by country is switched on for you, a row's parts are named and ordered the way its country writes them, in the language you read Postulo in; a row whose country you change is drawn that way once the page is saved. A postcode has to be in the form its country uses, and an address with a street or a postcode cannot leave empty a part every address there has. What is refused is said beside the part that is wrong. {% endblocktranslate %}

{% blocktranslate trimmed %} A town and a country alone are kept as a place. Nothing checks that an address exists, and a country Postulo has no rules for is free-form. {% endblocktranslate %}

{% blocktranslate trimmed %} An address recorded before addresses were checked, or brought in by a file, that its country would refuse today stays as it is, marked Kept as it was, and is checked the next time you change it. {% endblocktranslate %}

{% blocktranslate trimmed %} The filled star marks the primary. Your CVs and letters never print a street: they print the town and country of the primary address, unless Location in the contact block says something else. {% endblocktranslate %}

{% blocktranslate trimmed %} Unlike a telephone number, an address is not kept once on this instance, because people share a home; you cannot list the same one twice yourself. The bin removes a row at once, after asking, without waiting for Save. {% endblocktranslate %}
